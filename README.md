# MY.AC.P2MCA25104

Affordmed Campus Evaluation Project – Amrita University

## Projects Included

### 1. notification_app
Simple campus notification system using:
- Express.js
- REST APIs
- Middleware Authentication
- HTML/CSS/JavaScript Frontend
- Postman API Testing

Features:
- Get notifications
- Create notifications
- Mark notifications as read
- Delete notifications

---

### 2. vehicle_maintence_scheduler
Vehicle maintenance scheduling backend project using:
- Express.js
- Scheduling logic
- API integration
- Optimization concepts
- Depot-based maintenance selection

Features:
- Vehicle task scheduling
- Mechanic hour budgeting
- Task prioritization
- Schedule generation

---

### 3. logging_middleware
Custom logging middleware project using Express.js.

Features:
- Request logging
- API monitoring
- Middleware implementation
- Timestamp logging
